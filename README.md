# PortfolioHUB 🚀

Plataforma centralizada para exibir e gerenciar projetos digitais.

## 📋 Sobre o Projeto
O PortfolioHUB é uma plataforma que centraliza projetos digitais, 
permitindo gestão de versões, controle de acesso e colaboração 
utilizando GitHub e Google Workspace com apoio da IA Gemini.

## 🛠️ Tecnologias Utilizadas
- GitHub (controle de versão e colaboração)
- Google Gemini (apoio à implantação)
- Git (versionamento)

## 🔐 Segurança
- Branch `main` protegida com regras de Pull Request
- Aprovação obrigatória antes de merge
- Controle de acesso via Collaborators

## 🌿 Branches
| Branch | Função |
|--------|--------|
| `main` | Produção — protegida |
| `develop` | Desenvolvimento e testes |
